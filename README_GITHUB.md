# 从制造大国到智造强国

> 「人工智能+」如何重塑中国制造 · 成果汇报资料库

一个**零依赖、零构建、纯静态**的资料库网站。全部内容由 JSON 驱动，用浏览器直接打开，不需要后端、不需要安装依赖、不需要打包。

---

## 它是什么

这个项目把一次成果汇报整理成三层可交叉查阅的资料库：

| 层 | 入口 | 做什么 |
|---|---|---|
| **叙事层** | `#/story` | 按章节阅读主线内容（制造大国基础 → AI 重塑 → 时代青年使命），每段可下钻到对应资料条目 |
| **查询层** | `#/query` | 34 条资料卡片，支持搜索、分类筛选、年份 / 标题 / 章节三种排序，卡片 / 表格双视图 |
| **政策层** | `#/policy` | 直连国务院政策文件库公开接口，检索政策文件并跳转官方原文 |

封面 (`#/`) 提供三个入口。所有视图共用一套左侧导航，手机上自动收为汉堡菜单。

---

## 快速开始

**方式一：本地服务器（推荐）**

```bash
python -m http.server 8000
```

然后浏览器打开 <http://localhost:8000/>。Windows 用户也可以双击项目根目录的 `page.bat`。

**方式二：直接打开**

双击 `index.html`。现代浏览器可直接运行；若浏览器限制本地文件的 `fetch`，请改用方式一。

**部署**：整个目录上传到任意静态托管（GitHub Pages、Cloudflare Pages、Netlify 等）即可，无需构建步骤。

## 目录结构

```
.
├── index.html              # 页面骨架与三个入口
├── assets/
│   ├── app.js              # 路由、渲染、检索、政策层（原生 JS）
│   └── style.css           # 全部样式，含移动端适配
├── data/
│   ├── manifest.json       # 唯一配置入口：数据版本 + 文件清单
│   ├── meta.json           # 封面标题、副标题、版本文案
│   ├── items.json          # 查询层条目（34 条）
│   └── ch1.json / ch2.json / ch3.json   # 叙事层三章
├── page.bat                # Windows 一键起本地服务器
└── videos/                 # 视频资源占位目录
```

## 数据怎么维护

- **`data/manifest.json` 是唯一配置入口。** 改数据后把 `dataVersion` 加一（如 `v0.44` → `v0.45`），页面会自动刷新缓存，避免改了内容却看到旧数据。
- **叙事层**：每章一个 JSON，`sections[]` 里的 `paras[]` 是正文，`drill[]` 是该段可下钻的分类，`highlight[]` 是优先显示的条目 id。
- **查询层**：`items.json` 每条含 `id / title / category / year / summary / detail / links / verify` 等字段。新增条目和分类**不需要改代码**——分类筛选按钮是从数据里动态去重的。
- **按章节排序**：读取叙事层 `highlight[]` 的顺序给条目排位，同一小节内按 id 字典序，未被任何段落高亮的排在末尾。
- **Markdown**：正文只对 `**加粗**` 做结构化渲染；渲染前先转义 HTML，链接走安全白名单（只允许 `http(s)` / `mailto:` / 站内相对路径）。

### 关于 `verify` 字段

`verify: true` 会在页面显示「待核查」标记；`verify: false` 表示已完成核查，此时条目正文里的加粗才生效。当前全站均已定稿，无待核查内容。

## 内容与口径说明

- 所有事实、数字、引语均来自公开权威来源，逐字核对后写入；每个条目附有可点击的来源链接。
- **不同机构、不同机型、不同指标的数字不混用**；遇到来源冲突时，正文回避争议值，条目里说明冲突。
- 页面中的行业案例与公开数据只用于说明技术路径可行，**不等同于本汇报课题组自身的实测数据或研究结论**。
- 政策层只做检索与官方原文跳转，**不生成、不摘要、不解读政策文本**；政策文献索引卡只登记官方题名、发布主体、日期与原文链接，不作解读。
- 版本记录与来源索引保留在项目内部的审计文档中，不随公开版本发布。

## 技术选型

原生 HTML + CSS + JavaScript，无框架、无依赖、无构建。数据以 JSON 文件形式存放，通过浏览器 `fetch` 加载；路由用 URL hash 实现，便于静态托管与链接分享。

```
#/                    封面
#/story               叙事层
#/query               查询层（可带 ?cat=分类&hl=条目id&sort=章节&view=表格）
#/item/{id}           条目详情
#/policy              政策层
```

---

## 浏览器要求

需要支持 `fetch` 与 URL hash 的现代浏览器（Chrome / Edge / Firefox / Safari 近两年版本）。已在桌面浏览器上验证；移动端布局自适应。
