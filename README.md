## 核心特性

- 🧭 **三层视图**：叙事层读主线、查询层查数据、政策层检索官方文件，一个站点交叉索引。
- 🪶 **零依赖零构建**：原生 HTML + CSS + JavaScript，无 npm、无打包、无框架，静态文件即全部产物。
- 🗂️ **数据驱动**：16 个叙事小节、34 条查询条目全部由 `data/*.json` 描述；改内容不用碰代码。
- 🔍 **检索与排序**：关键词搜索、分类筛选、年份 / 标题 / 章节三种排序，卡片与表格双视图。
- 🔗 **逐条溯源**：事实与数字均附权威来源链接；来源冲突时正文回避争议值、条目内说明冲突。
- 🛡️ **安全渲染**：正文先转义再解析加粗，链接走白名单，拒绝脚本与目录穿越协议。
- 📱 **移动适配**：桌面侧栏在窄屏收为汉堡菜单，iPhone 上可直接阅读与下钻。

## 使用流程

启动本地服务器（Windows 可直接双击 `page.bat`）：

```bash
python -m http.server 8000
```

浏览器打开 <http://localhost:8000/>，随后按下列入口操作：

| 入口 / 按钮 | 作用 |
|---|---|
| 封面「进入叙事层」 | 按章节阅读主线正文，每段末尾可下钻到对应资料 |
| 封面「进入查询层」 | 搜索、按分类筛选、切换排序与卡片 / 表格视图 |
| 封面「进入政策层」 | 直连国务院政策文件库检索，结果外链 gov.cn 官方原文 |
| 侧栏「查看相关数据 →」 | 从叙事段落跳到查询层，并高亮该段对应的卡片 |
| 查询层卡片 | 展开详情：逐字原文、权威数字、来源链接与口径边界 |
| `#/item/{id}` | 条目直链，可直接分享某一条资料 |

## 数据安全声明

**无后端服务、无账号体系、不写入 Cookie 或 LocalStorage。** 页面内容来自随站点分发的静态 JSON 文件，由浏览器直接读取；所有检索、筛选与排序都在本地完成。

唯一对外网络请求来自**政策层**：按需向国务院政策文件库公开接口发起只读检索，结果仅以链接形式跳转到 `gov.cn` 官方原文。政策层不生成、不摘要、不解读任何政策文本。

## 已知限制 / 彩蛋说明

- 直接双击 `index.html` 时，部分浏览器会限制本地 `fetch`；请用本地服务器方式打开。
- 政策检索依赖第三方公开接口的可用性与网络环境；接口不可用时其余两层不受影响。
- 内容为特定主题的静态快照，不代表实时数据；来源链接的时效性以官方页面为准。
- 本项目未植入隐藏彩蛋或源码签名。F12 控制台仅保留一行启动错误日志 `[boot]`，用于数据加载失败时排障。
